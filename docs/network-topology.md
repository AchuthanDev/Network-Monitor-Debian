# Network Topology

## `server_only` Mode

```text
Internet
   |
Tenda HG7 / existing router
   |
192.168.1.0/24
   |
Debian server
```

The Debian server is a monitored host, not the LAN gateway. The system only claims accurate Internet totals for traffic generated by the Debian server itself. LAN transfers, Docker internal traffic, and loopback traffic are excluded from ISP usage.

## `gateway` Mode

```text
Internet
   |
Tenda HG7
192.168.1.1
   |
WAN-side interface
Debian gateway / monitor
LAN-side interface
192.168.50.1/24
   |
Monitored LAN clients
192.168.50.0/24
```

Gateway mode requires client devices to use Debian as their default gateway. Accurate per-device accounting is only valid in that topology.

## Interface Roles

- WAN-side interface: reaches the existing router/Internet.
- Monitored LAN interface: serves only monitored client devices.
- Docker bridges: remain separate internal networks and must not overlap the monitored LAN CIDR.

Current inspection showed `enp0s31f6` and `wlp1s0` on `192.168.1.0/24`. A USB Gigabit Ethernet adapter is the recommended monitored LAN interface unless Wi-Fi AP support is verified.

## NAT Path

```text
Client 192.168.50.21
  -> Debian LAN interface
  -> pre-NAT forward accounting
  -> masquerade on WAN interface
  -> HG7
  -> Internet
```

Accounting must happen before NAT so the source remains the client IP/MAC rather than the Debian WAN IP.
